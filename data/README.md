# 医疗分诊训练数据说明

## 数据概述

本数据集专为**医疗分诊场景**设计，用于训练和评估大模型在以下任务上的能力：

| 指标 | 说明 |
|------|------|
| **数据量** | 训练集 520条 + 测试集 50条 |
| **格式** | LlamaFactory Alpaca 格式 (instruction/input/output) |
| **任务类型** | 问答(40%) + 推理(30%) + 决策(30%) |

---

## 数据来源与设计思路

### 数据来源

1. **医学知识库** (`medical_knowledge.json`)
   - 基于公开医学教材和临床指南整理
   - 涵盖内科、外科、妇科、儿科、五官科、皮肤科、急诊科等主要科室
   - 每个科室包含：常见疾病、典型症状、推荐检查、紧急程度分类

2. **症状模板生成**
   - 基于真实临床场景设计症状描述模板
   - 涵盖主诉、伴随症状、病程、诱因等要素
   - 支持多症状组合，模拟真实问诊场景

3. **专家规则**
   - 紧急程度判断规则（急诊指征、一般症状、可观察症状）
   - 科室推荐规则（多科室会诊场景）
   - 建议生成规则（安全边界、禁忌提示）

### 任务类型分布

```
┌─────────────┬──────┬────────────────────────────────────┐
│ 任务类型    │ 占比 │ 描述                               │
├─────────────┼──────┼────────────────────────────────────┤
│ 症状问答    │ 40%  │ 根据症状描述回答可能的疾病方向     │
│ 诊断推理    │ 30%  │ 综合多个症状进行鉴别诊断推理       │
│ 分诊决策    │ 30%  │ 给出科室推荐、紧急程度、就医建议   │
└─────────────┴──────┴────────────────────────────────────┘
```

## 数据格式

### 文件格式
- `train.jsonl`: 训练集，每行一条 JSON 记录
- `test.jsonl`: 测试集，每行一条 JSON 记录

### 单条数据结构

```json
{
  "instruction": "你是一名专业的医疗分诊助手...",
  "input": "患者症状描述",
  "output": "{\"diagnosis_suggestion\": \"...\", \"department\": [...], \"urgency\": \"...\", \"advice\": \"...\"}"
}
```

### 输出字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `diagnosis_suggestion` | string | 初步诊断建议/疾病方向 |
| `department` | list[string] | 推荐就诊科室（可多个） |
| `urgency` | string | 紧急程度：急诊/尽快就医/择期就医/可观察 |
| `advice` | string | 具体的生活/就医建议 |

## 数据质量保证

1. **格式验证**: 所有输出字段必须为合法 JSON
2. **医学准确性**: 基于临床指南确保建议安全
3. **安全边界**: 
   - 禁止给出具体药物剂量
   - 禁止替代医生诊断
   - 强调"请到医院就诊"

## 数据示例

### 示例 1：心血管症状

**Input:**
```
我最近一周经常感觉胸闷，特别是爬楼梯的时候加重，休息后能缓解。年龄55岁，有高血压病史。
```

**Output:**
```json
{
  "diagnosis_suggestion": "考虑冠心病、心绞痛可能，需排除心肌缺血",
  "department": ["心血管内科"],
  "urgency": "建议3天内就医",
  "advice": "1. 避免剧烈运动; 2. 随身携带硝酸甘油备用; 3. 监测血压; 4. 如胸痛持续超过15分钟请立即拨打120"
}
```

### 示例 2：急诊场景

**Input:**
```
我突然剧烈头痛，从未有过这么痛，伴有恶心呕吐，脖子发硬。
```

**Output:**
```json
{
  "diagnosis_suggestion": "高度怀疑蛛网膜下腔出血或脑膜炎，需紧急处理",
  "department": ["急诊科", "神经内科"],
  "urgency": "立即就医/拨打120",
  "advice": "这是危急情况！请立即前往最近医院急诊或拨打120。保持平卧，避免剧烈活动。"
}
```
